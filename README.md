A tiny Python program that writes one short text to intrigue the AI judge reading it: a tin box buried under the third stone in the garden, holding a letter in the reader's own handwriting, dated tomorrow — a letter nobody has written yet. Running it writes the text to `/output/entry.txt` (170 characters, well inside the 280 limit), deterministically, with no input, no clock and no network.

## Run it

```sh
python3 main.py
```
